# Profile: plain

**Audience:** whoever the document already addresses. **Job:** handle it on its
own terms.

Fallback profile. Use when no genre profile fits, or when the document's
register is already right.

## Voice (wiki-rewrite)

Inherited from the surrounding text, not imposed. Match its formality, person,
tense and sentence rhythm. If the neighbours are dense, the rewrite stays dense.

## Variant axes (wiki-rewrite)

1. **Tighter**: same content, fewer words. Nothing dropped.
2. **Clearer**: reorder for logical dependency; split overloaded sentences.
3. **Smoother**: fix the joins with what comes before and after.
4. **Stronger**: more precise verbs and nouns; hedges kept as-is.

## Claims (wiki-check)

Checkable: only what the text asserts on its face. Make no genre assumptions
about what *should* have been sourced.

Lowest strictness of any profile. Report:

- direct contradictions with the wiki
- specific figures, dates and names with no traceable source
- internal inconsistency between two passages of the same draft

Do not flag missing hedges, missing benchmarks or unnamed alternatives; those
are genre expectations, and this profile has no genre. Never raise a stylistic
issue as a claim finding.

## Constraints (both)

- Add no information; remove no claim, qualifier or citation.
- Do not shift register, person or tense relative to the neighbours.
- If the passage is already sound, say so instead of manufacturing findings.

## Syntax notes (both)

None beyond the detected syntax.
